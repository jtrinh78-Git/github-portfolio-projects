# Python API Data Client

A Python application that retrieves user data from a REST API and allows users to search for information by name.

## Features

- Fetches user data from a REST API
- Checks HTTP response status codes
- Converts JSON responses into Python data
- Searches users by name
- Supports case-insensitive searches
- Displays nested address, location, and company data
- Handles missing users
- Handles connection errors 

## Skills Used 

- Python
- REST APIs
- HTTP GET requests
- JSON parsing
- Lists and dictionaries
- Nested dictionary access
- For loops
- Conditional statements
- User input
- Boolean flags 
- Exception handling

## How to Run

Install the required package:

python3 -m pip install requests

Run the program:

python3 api_client.py
