# Embedding & Vector Foundations

A Python project demonstrating the foundations of embeddings, vectors, cosine similarity, and semantic search using the OpenAI API.

## Features

- Converts text into embedding vectors
- Inspects embedding values
- Implements cosine similarity in Python
- Compares semantic meaning between texts
- Creates embeddings for multiple documents
- Embeds a natural-language query
- Compares the query against document vectors
- Retrieves the document with the highest similarity score

## Concepts Practiced

- OpenAI embeddings
- Vector representations
- Dot product
- Vector magnitude
- Cosine similarity
- Semantic search
- Python loops
- Lists and `.append()`
- Index-based retrieval
- Environment variables
