# REST API Automation

A Python program that automates REST API operations using the requests library.

## Features

- Create data with POST
- Update data with PUT
- Delete data with DELETE
- Check HTTP status codes
- Read JSON responses
- Choose an API operation with user input

## Concepts Practiced

- REST APIs
- HTTP methods
- JSON
- Python dictionaries
- if / elif / else
- User input
- API responses
- HTTP status codes

## Run

python3 api_automation.py
